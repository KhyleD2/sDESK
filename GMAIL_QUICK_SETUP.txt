  📧 GMAIL SETUP - 3 SIMPLE STEPS
═══════════════════════════════════════════════════════════════

🔐 STEP 1: Get Gmail App Password
───────────────────────────────────────────────────────────────
1. Go to: https://myaccount.google.com/apppasswords
2. Click "Generate" for Mail app
3. Copy the 16-character password (like: abcd efgh ijkl mnop)

📝 STEP 2: Update .env File
───────────────────────────────────────────────────────────────
Open: d:\sentrydesk\.env

Find these lines and replace:
   MAIL_USERNAME=your-gmail@gmail.com
   MAIL_PASSWORD=your-app-password-here

With YOUR credentials:
   MAIL_USERNAME=khyled2@gmail.com          👈 YOUR GMAIL
   MAIL_PASSWORD=abcdefghijklmnop           👈 YOUR APP PASSWORD

✅ STEP 3: Test It
───────────────────────────────────────────────────────────────
Run in terminal:
   php artisan config:clear
   php artisan serve

Then:
1. Register at: http://localhost:8000/register
2. Use YOUR Gmail as the email
3. Login - check your Gmail inbox for the 2FA code!

═══════════════════════════════════════════════════════════════

⚠️ IMPORTANT NOTES:
───────────────────────────────────────────────────────────────
✓ Use APP PASSWORD (not your regular Gmail password!)
✓ Enable 2-Step Verification first (required for app passwords)
✓ Remove spaces from the app password when pasting
✓ Check Spam folder if email doesn't arrive
✓ Run "php artisan config:clear" after any .env changes
